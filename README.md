## ea-bang 
microservice + tiny frontend to resolve browser search engine shortcuts and redirect the query to corresponding search engine

#### Installation
```
git clone https://github.com/hagb4rd/ea-bang.git
cd ea-bang
npm install
npm link
```

#### Running server and web-ui
``` 
ea-bang 
```
